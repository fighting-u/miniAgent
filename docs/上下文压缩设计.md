# 上下文压缩设计

## 触发时机

| 触发入口 | 执行时机 |
| --- | --- |
| 轮前自动（`pre_turn`） | 开始turn之前，新用户输入不压缩 |
| 轮内自动（`mid_turn`） | 一turn内，每次工具批量执行完还未结束，下一次请求llm前 | 
| 手动命令（`/compact`） | 用户发送 `/compact` 时 | 

## 压缩流程/算法

1. **请求摘要**：以原历史拷贝，加请求压缩提示词 `COMPACT_PROMPT` 构造工作副本，调用辅助llm生成交接摘要。
2. **超窗裁剪重试**：若请求压缩本身的上下文发生超限错误，从工作副本头部移除最旧的item级单元（`function_call` 与同 `call_id` 的 `function_call_output` 成对删除）并重试；至少保留最后一个历史单元加摘要指令，仍超窗或摘要未完成/为空时报错，后期配合ui提示；
3. **保留用户原话**：从原历史末尾向前遍历，按默认2w token预算筛选真实 `role=user` 消息：
   - 按 `summary_index` 跳过旧摘要;
   - 图文混合消息仅保留文本块，纯图消息替换为 `[历史图片已省略]`；
   - 首条超出剩余预算的消息按 UTF-8 字节做首尾各留一半，中间截断并插入 `…中间已省略 N 字节…` 标记；
   - 反转恢复时间顺序，末尾追加 `SUMMARY_PREFIX + "\n" + summary_text` 作为新的摘要消息。
4. **提交切换**：检查点写入 JSONL 成功后，原地切片替换 `session.messages`，更新 `summary_index`。


## 3. 模型窗口与上下文估算

- **窗口与策略配置**：
  - 模型原始上下文窗口作为静态元数据集中在 `src/models/registry.py`（`ModelInfo`），每个会话持有 `model_info`，压缩器按会话动态计算有效窗口与自动阈值（`context_window * auto_compact_percent // 100`）。
  - 公共策略参数放在 `config.yaml`：`effective_window_percent`、`auto_compact_percent`、`compact_keep_user_tokens`。
- **校准式估算（`src/compact/estimator.py`）**：
  - 有上次普通主响应的 `last_total_tokens` 基准时，直接按 `last_total_tokens + 尾部未覆盖消息估算` 计算，避免重复扫描系统提示词与工具定义。
  - 冷启动、压缩刚清空基准时，走全量估算：`系统提示词（延迟构造） + 工具定义 + 全部消息`。
- **单项估算规则**：
  - 文本与序列化结构按 UTF-8 字节估算：`⌈bytes / 4⌉`。
  - 图片块剥离原始数据后单独按尺寸估算：从本地 Data URL 头部读取宽高并按 `32×32` 网格向上取整，单图上限 `10,000`；非本地或解析失败按上限计且不联网。

## 5. 持久化、恢复与用量统计

- **检查点（`compacted`）**：每次成功压缩向原 JSONL 追加一条 `type="compacted"` 记录，保留压缩前的完整历史不删改。`payload` 为新历史列表，`metadata` 记录本次摘要消耗与累计总消耗。
- **用量记录（`token_usage`）**：每次普通主响应落盘后追加一条 `token_usage` 行，记录实际 `total_tokens` 并更新内存基准（`last_total_tokens`、`covered_items`）；摘要响应失败但返回了用量时也记入累计。长期记忆的召回与提取不计入会话用量。
- **快速恢复**：加载会话或异常 `reload()` 时，从 JSONL 文件尾部逆向查找最后一条 `compacted` 检查点，直接用其初始化上下文并顺序重放后续记录；无检查点则兼容旧文件从头恢复。
- **记忆隔离**：长期记忆召回与后台提取通过 `summary_index` 过滤交接摘要，避免把模型总结当作用户原话。

## 6. 相关模块

| 模块 | 职责 |
| --- | --- |
| `src/models/registry.py` | 维护模型上下文窗口静态元信息（`ModelInfo`） |
| `src/compact/compactor.py` | `ContextCompactor`、超窗裁剪重试、用户原话筛选与历史重建 |
| `src/compact/estimator.py` | 文本、图片、消息项与校准式上下文估算 |
| `src/compact/constants.py` | 摘要固定前缀常量 `SUMMARY_PREFIX` |
| `src/session/session.py` / `session_manager.py` / `storage.py` | `SessionTokenUsage`、`summary_index`、`compacted` / `token_usage` 落盘与检查点恢复 |
| `src/message_process/turn_runner.py` / `message_processor.py` | 轮前/轮内自动检测、`/compact` 命令接入与会话占用互斥 |
