
| 输入 | 行为 |
| --- | --- |
| 普通文字 | 开始新的用户请求，持久化后调用 Agent。 |
| `/new` | 常驻端准备新会话，客户端切换标识并清屏；首次实际用户输入时才创建文件，保留原会话和文件。 |
| `/resume` | 终端发送 LIST_SESSIONS，本地菜单选择后查询 GET_HISTORY 并采用该 ID；QQ 返回会话列表，通过 `/resume <id>` 恢复。 |
| `/delete` | 从同样的会话列表选择，二次确认后删除该会话文件；若是当前会话，清屏并开启新会话。 |

命令统一归为 InboundType.COMMAND，不按命令名展平类型。终端程序主动查询使用 GET_HISTORY、LIST_SESSIONS；这些查询和命令都不进入模型上下文。`/new`、`/resume <id>` 产生明确的 session 切换事件，QQChannel 据此更新自身 session_id，不影响其他通道。入口选择持久化在 `sessions/bindings`，不再使用全局默认会话。
