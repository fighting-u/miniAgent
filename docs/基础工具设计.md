# 基础工具设计

本文记录现有内置工具的调用方式、文件操作和权限管控。工具定义与处理函数位于 `src/tools/tools.py`，权限规则位于 `src/agent/hook.py`，调用调度位于 `src/agent/core.py`。MCP 扩展工具另见 [MCP 接入设计](mcp接入设计.md)。

## 工具与调用流程

`TOOLS` 使用 OpenAI Responses 的 function 工具格式声明名称、说明和参数结构；`TOOL_HANDLERS` 将工具名称映射到本地处理函数。

| 工具名 | 处理入口 | 当前行为 |
| --- | --- | --- |
| `get_model_name` | `run_get_model_name` | 无参数，读取环境变量 `MODEL`，返回当前请求配置的模型名称；未配置或为空时记录警告日志并返回错误提示。 |
| `get_current_time` | `run_get_current_time` | 无参数，读取系统本地当前时间，以带时区偏移的 ISO 8601 格式返回，精确到秒，例如 `2026-11-11T15:30:45+08:00`。 |
| `powershell` | `run_powershell` | 启动 Windows PowerShell 执行命令，返回退出码、标准输出和标准错误；超时为 120 秒。 |
| `read_file` | `run_read` | 按 UTF-8 读取文本，可通过 `limit` 限制返回行数。 |
| `write_file` | `run_write` | 按需创建父目录，以 UTF-8 创建文件或覆盖已有文件的全部内容。 |
| `edit_file` | `run_edit` | 读取 UTF-8 文本，仅替换第一次出现的 `old_text`；未找到时返回错误。 |
| `glob` | `run_glob` | 按模式查找路径，支持 `**` 递归；过滤工作区外结果，排序后最多返回 200 项。 |
| `update_plan` | `run_update_plan` | 整体替换当前计划，最多 20 项，同时最多一项为 `in_progress`。 |
| `load_skill` | `SKILL_LOADER.load` | 按技能名称加载完整说明。 |
| `load_memory` | `load_memory` | 按文件名读取长期记忆，详见 [长期记忆设计](长期记忆设计.md)。 |
| `compact` | 主循环单独处理 | 先返回接收提示，待本批工具调用结束后归档并压缩上下文，详见 [记忆压缩设计](记忆压缩设计.md)。 |

主循环按顺序执行模型返回的工具调用：解析 `arguments` JSON → 触发 `PreToolUse` → 分发工具 → 触发 `PostToolUse` → 保存并展示结果。前置 Hook 返回非 `None` 时跳过执行，将拦截说明作为结果返回。

模型名称与主循环发送请求时使用的 `MODEL` 环境变量一致，返回的是请求配置名称，不查询服务端实际部署的模型。时间使用操作系统的本地时区，并在结果中包含对应的 UTC 偏移，不固定为 UTC+8。

工具结果以字符串放入 `function_call_output.output`，保留原调用的 `call_id`。JSON 解析错误和参数调用产生的 `TypeError` 返回“工具参数无效”；未知工具返回名称提示。文件工具内部捕获异常并返回 `Error: ...`，PowerShell 分别处理超时和进程启动失败。

## 文件路径与工作区

`WORKDIR = Path.cwd().resolve()` 在工具模块加载时确定，通常就是启动程序时的当前目录，并不固定为源码目录。

`read_file`、`write_file`、`edit_file` 都先调用 `safe_path`：

```python
resolved_path = (WORKDIR / path).resolve()
if not resolved_path.is_relative_to(WORKDIR):
    raise ValueError(f"Path escapes workspace: {path}")
```

相对路径以 `WORKDIR` 为基准；完整绝对路径直接采用自身，`Path` 的 `/` 运算不是字符串拼接。解析 `..` 等路径成分后，最终目标必须位于工作区内。

假设工作区为 `D:/projects/others/miniAgent`：

| 输入路径 | 结果 |
| --- | --- |
| `test.txt` | 允许，指向工作区根目录的文件。 |
| `output/test.txt` | 允许；写入时自动创建缺失父目录。 |
| `D:/projects/others/miniAgent/test.txt` | 允许，属于工作区内的绝对路径。 |
| `D:/other/test.txt` | 拒绝，目标在工作区外。 |
| `../test.txt` | 拒绝，解析后目标在工作区外。 |

`glob` 不调用 `safe_path`，而是对匹配结果逐个进行工作区归属检查。文件操作最终仍受操作系统权限约束。

## 权限管控

权限分为工具执行前的 Hook 审查和文件处理函数内部的路径检查。**当前 `permission_hook` 的注册行已注释，Hook 审批流程未启用；`safe_path` 和 `glob` 的路径过滤仍然生效。**

`hook.py` 已定义的审批流程如下，启用 `register_hook("PreToolUse", permission_hook)` 后才会执行：

1. **硬拒绝**：PowerShell 命令转为小写后匹配 `DENY_LIST`。包含格式化卷、清空磁盘、关机等已配置片段时直接拒绝，不进入审批。
2. **敏感操作识别**：`read_file`、`write_file`、`edit_file` 指向工作区外时请求审批；PowerShell 命中删除或清空命令正则，或包含 `set-content`、`out-file`、`set-acl`、`icacls`、`takeown` 等已配置片段时请求审批。
3. **用户决定**：终端展示工具名、参数和审批提示，只有 `y` 或 `yes` 表示允许，其他输入均拒绝。拒绝后向模型返回“权限被拒绝。”。

未命中规则的调用直接放行；当前没有“工作区内写入或覆盖文件也必须确认”的规则。其他内置工具及 MCP 工具也经过前置 Hook，但现有审批规则只针对上述文件工具和 PowerShell。

### 当前边界

- Hook 审批没有与 `safe_path` 联动。即使启用审批并同意工作区外访问，文件处理函数仍会拒绝该路径，目前没有审批后临时放行机制。
- PowerShell 使用执行时的 `os.getcwd()` 作为初始目录，没有调用 `safe_path`，命令可以访问工作区外路径。关键词和正则规则只是有限匹配，不构成命令解析器或操作系统沙箱；当前审批 Hook 未启用时，这些命令规则也不会执行。
- 直接调用处理函数会绕过 Hook 审查；文件函数自身的路径检查仍执行。
- 已注册的日志 Hook 记录工具名称、参数预览、结果预览和大输出提醒；启用权限 Hook 后，审批请求、决定和硬拒绝也会记录日志。大输出提醒本身不截断或拦截结果。

本文件按当前代码整理；本次新增模型名称和当前时间工具，未运行测试。
